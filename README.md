# StreamVibe – Лендинг стримингового сервиса

StreamVibe — многостраничный сайт стримингового сервиса на Minista (статическая генерация на JSX). Вся интерактивность написана вручную: кастомный видеоплеер (перемотка мышью и касанием, управление громкостью, fullscreen, горячие клавиши), доступный селект и табы по паттернам WAI-ARIA с полной клавиатурной навигацией, оверлей-меню на нативном <dialog>. Модули реализованы по единому паттерну на data-атрибутах с реактивным состоянием на Proxy. Адаптивность синхронизирована между CSS и JS через matchMedia. Слайдеры на Swiper, маски ввода на IMask, стили на SCSS с PostCSS (pxtorem), генератор компонентов Plop.

Стек: Minista, JSX, JavaScript, SCSS, PostCSS, Swiper, IMask.
